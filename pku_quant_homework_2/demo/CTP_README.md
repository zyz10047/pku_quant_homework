## 二、遇到的真实问题：`140 首次登录必须修改密码`

### 现象

```
[21:02:20.187] 终端认证成功，开始登录
[21:02:20.260] 交易登录失败：140 CTP:首次登录必须修改密码，请修改密码后重新登录。密码至少10位、3种字符类型
```

### 诊断过程

1. **初始猜测**："3 不合法的登录"（7×24 环境报错）→ 以为账号/权限问题
2. **切到交易时段环境**（30001/30011）后，错误码变为 **`140`**，**原因瞬间明确**
3. **关键发现**：**7×24 环境和交易时段环境的错误诊断精度不同**——
   - 7×24 环境只报笼统的"不合法"
   - 交易时段环境报**具体的 `140 首次登录必须修改密码`**

### 为什么网站能登、交易系统不能登

SimNow 有**两套独立的密码体系**：

| 体系 | 用途 | 状态 |
|---|---|---|
| 网站/客户端登录 | 管理账号、看资金 | ✅ 能登 |
| **交易系统（CTP）密码** | 程序连柜台用 | ❌ **首次必须改密** |

**首次使用 CTP 交易系统时，即使密码本身合规，也强制要求走一次"改密码"流程**。

### 尝试过的解决方案

1. **API 改密**（`ReqUserPasswordUpdate`）：
   - 写了 `ctp_reset_password.py`，调用 CTP 改密接口
   - **结果**：请求发出，但**60 秒无响应**——可能要求"已登录状态"才能改密，但登录又被拒 → **死锁**
   
2. **查 SimNow 官网**：
   - 公告确认"新注册用户需要等到第三个交易日才能使用第二套环境"
   - 但 `140` 错误码出现在**第一套环境**，说明**改密是独立要求**

### 结论

**`140 首次登录必须修改密码` 是 SimNow/CTP 的一次性安全要求，必须通过官方 GUI 客户端完成，纯 API 途径走不通**。

## 三、系统设计（代码逻辑）

### 闭环流程

```
连接 → 认证 → 登录 → 订阅行情 → 打印行情
  ↓
收到第一个目标合约行情 → 以对手价买入开仓 1 手
  ↓
成交回报到达 → 以对手价卖出平仓 1 手
  ↓
打印"闭环成功"（持仓归零、无活动委托）
```

### 关键设计

- **对手价下单**：买用卖一价、卖用买一价，**确保立即成交**
- **防重复下单**：用 `order_done` 标志位
- **开仓成交触发平仓**：`onRtnTrade` 回调中检测开仓成交，自动平仓
- **凭据安全**：密码从 `config_local.py` 读取（已 gitignore，**绝不上传**）

### 代码结构

| 文件 | 说明 |
|---|---|
| `ctp_demo.py` | 主程序（连接 + 订阅 + 下单闭环）|
| `config_local.py` | 本地配置（含密码，**已 gitignore**）|
| `config_template.py` | 配置模板（可入库）|
| `ctp_reset_password.py` | 首次改密尝试（未完成）|
| `flow/` | CTP 运行时流文件（自动生成，**已 gitignore**）|

## 五、踩过的坑（技术细节）

### 坑 1：CTP 常量名大小写敏感

**错误**：`THOST_FTDC_D_BUY` / `THOST_FTDC_OPT_LIMITPRICE`  
**正确**：`THOST_FTDC_D_Buy` / `THOST_FTDC_OPT_LimitPrice`

**最佳实践**：**不要硬编码，直接从 `vnpy_ctp.api.ctp_constant` import**：

```python
from vnpy_ctp.api.ctp_constant import (
    THOST_FTDC_D_Buy,      # '0' 买
    THOST_FTDC_D_Sell,     # '1' 卖
    THOST_FTDC_OF_Open,    # '0' 开仓
    THOST_FTDC_OF_Close,   # '1' 平仓
    THOST_FTDC_OPT_LimitPrice,  # '2' 限价（注意不是 '0'）
    THOST_FTDC_TC_GFD,     # '3' 当日有效
    THOST_FTDC_VC_AV,      # 任意数量
    THOST_FTDC_HF_Speculation,  # 投机
    THOST_FTDC_CC_Immediately,  # 立即
)
```

### 坑 2：CTP 常量是 `str` 不是 `bytes`

**错误**：`b"0"`  
**正确**：`"0"`（或直接用常量）

### 坑 3：`LimitPrice` 的值是 `'2'` 不是 `'0'`

CTP 的 `OrderPriceType` 枚举里，`LimitPrice = '2'`（限价），**不是直觉的 `'0'`**。
